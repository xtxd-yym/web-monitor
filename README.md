## GitHub 备份边界

此仓库为公开仓库，仅保留适合公开存储的代码、必要配置、AGENTS.md 和 README.md。
客户问题、内部接入说明、追踪文档、周会材料、截图、原始导出、日志、旧演示页及构建产物只保留本地。

公司专用 Dockerfile、npm 源配置，以及按既定过滤策略仅留本地的两个实现文件也不进入公开备份：

- `后端服务/src/services/sourcemapOss.js`
- `监控sdk源码/src/server/server.js`

因此 **GitHub clone 不是完整部署副本**，缺少这些文件时校验会提示缺失；不能直接拿它替代公司发布仓库。笔记本完整目录仍保留交付原文件。公司虚拟机维护三个独立仓库，通过保留历史的 dev → feature MR 导入或更新。

取消跟踪只影响新版本，不会清除 GitHub 已有历史里的文件；本次不改写历史、不强制推送。
